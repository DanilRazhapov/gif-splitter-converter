# gif-splitter-converter
.mp4 to .gif converter and gif splitter for Steam Workshop illustrations, all working directly in browser

## Features
- Converting .mp4 file into .gif
- Splitting .gif into 5 pieces, each 150px wide

## How to Use

### Split .gif 

- Choose Gif Splitter in navigation menu
- Drag&drop or choose .gif file
- Click on 'Split and Download' button

### Convert .mp4 to .gif

- Choose Mp4 Converter in navigation menu
- Drag&drop or choose .mp4 file
- Click on 'Convert and Download' to convert to .gif
- Click on 'Convert and Split' to convert to .gif and split into 5 pieces

## Stack
TypeScript, React, gifenc, gifuct-js, gif.js, jszip, ffmpeg.wasm, radix-ui.
